Short Description:
This web application is an interactive fan website for the Britpop band Oasis built upon the midterm static website. It allows users to browse band member profiles, view album covers in an interactive gallery, search and filter favorite songs, manage playlist records using full CRUD operations, and validate fan registration input with client-side feedback.

Features Implemented:

Dynamic Search and Filter: Real-time search bar and category filter buttons to sort songs by album without page reloads.

Dynamic Table with CRUD Operations: Allows users to view songs, add new entries, edit existing song titles and albums inline, and delete songs with a modal confirmation dialog.

Interactive Image Gallery: Clickable album covers opening in a custom lightbox modal featuring keyboard navigation, previous/next controls, and smooth fade transitions.

Client-side Form Validation: Registration form checking required fields, regex email syntax, password strength indicators (weak, medium, strong), and matching password confirmation.

Responsive Layout and Styling: Fully responsive user interface built using HTML5, CSS3, custom theme styles, and Bootstrap 5.
